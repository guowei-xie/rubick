# L1 运营视角续报率班型深拆归因

视角：运营（view=operations）。这是「选定某班型后再往下深拆」的下游下钻，按 市场(SKU+渠道)/TMK(定标班型)/运营(团队承接+团队率) 三分归因；与市场侧 wf_l1_renewal_full_attribution 互补、不重复。运营按实际运营学期，无成熟度修正——续报量直接用观测值。

## 前置命中判定
仅用于对**选定单个/大班型**（智配、科特直播、召回、思维直播等）的续报率**变化**做深拆。整体全班型缺口归因先用班型级「结构 vs 率」总览定位主因班型，本卡不承担。指标可切换：首日续报率 `renew_t0/leads`、期内续报率 `renew/leads`，方法不变。数据源=运营集市 `fact_operations_actual`。

## 步骤

### 1. 定场景 · 确认拆解链
确认班型、指标（首日/期内）、基准（环比/同比）。智配为新项目无同比基期，只做环比。按班型类型定链：
- 常规班型（科特/召回等）：2 层 `SKU(市场) → 团队(运营：承接结构+团队率)`。
- 智配：3–4 层 `SKU(市场) → 渠道(市场) → 定标班型(TMK) → 团队(运营)`。
- 单渠道班型（召回）跳过渠道层、运营层拆 `城市×SKU`；多团队班型（科特）运营层拆 `团队×SKU`。
TMK 定标班型归属留专题、暂不强归；智配「未进班/未分配」是 TMK 层独立一级（率恒 0）。

### 2. 逐层嵌套结构归因（`mth_l1_nested_structural_attribution` + `mth_l1_structural_attribution`）
每层用中心化恒等式：结构影响 `(w1−w0)(r0_group−r0_parent)` + 率影响 `w1(r1−r0)`，拆的是上一层「内率」（残差），`本层结构影响 + 下一层内率 = 上层内率`，全链相加 = 整体变化，逐层验证闭合。率先汇总分子分母再相除。新增分组基期率不可得时 `r0:=r1` 保闭合，禁填 0。运营层必须拆到 SKU 维度证明率变化普遍性。

### 3. 同格可比破 Simpson
团队最细单元须「同 SKU 同班型可比」；边际率可能与可比执行率方向相反，归因只认可比口径、边际率不作执行结论，附最细单元证据表。

### 4. 细粒度去噪
细粒度质量核查用经验贝叶斯收缩 `r_adj=(n·r_unit+K·r_parent)/(n+K)`，K≈300；收缩后接近父层的判噪声、不入主链。质量核查覆盖所有渠道，渠道结构变差本身即质量问题。

### 5. 季节性校准（`mth_l1_seasonal_class_calibration`，涉强季节班型时）
对强季节班型（召回等）：幅度对比（本期环比提升 vs 去年同期同区间提升）+ 绝对水平对比（本期绝对率 vs 去年同期），区分「季节性兑现」与「运营真实贡献/缺口」，不把季节性波动误记为运营改善。

### 6. 偏低群体点名 + 建议
逐行核对，点名 <100% 或负贡献偏低群体（整体超标≠局部无短板）；建议给对象+动作+预期，不外推。

## 输出
1. 续报率整体结论
2. 逐层嵌套归因表（逐层内率闭合、Σ 闭合、总计行）
3. 季节性校准判断（如涉强季节班型）
4. 偏低群体点名
5. 可执行建议

## 护栏
- 单一数据源闭合，运营源不跨市场源拼接。
- 智配新项目只做环比、不做同比。
- 不仅拆最大班型；下钻不用分摊预测补充量。
- 小分母噪声需收缩去噪、不当信号。
