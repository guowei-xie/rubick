# L1 招生体检（达成 + 趋势）

本工作流合并原 B1（招生目标达成诊断）与 B2（招生趋势/历史变化诊断），覆盖「现在达没达标」与「比之前好/差」两个心智模型；用户问哪个分支，路由到对应输出形态。

## 适用问题
- **达成视图**：当前期招生是否达标；指定渠道缺口/超额来自哪里。
- **趋势视图**：当前期招生较历史基准期是增长/下滑/持平；变化主要来自哪些 `业务核算组 + 定标渠道类型`；招生变化的同时续报率是改善还是走弱；目标达成率反映相对预期改善还是走弱。

## 不适用范围
- 续报率结构归因（走 `wf_l1_renewal_full_attribution`）。
- 过程转化漏斗归因（走 `wf_l1_process_funnel_diagnosis`）。
- 渠道趋势图片解读（走 `wf_l1_channel_trend_diagnosis`）。
- 完整渠道扫描报告（无固化容器，按需手工组装）。

## 必要输入
| 输入 | 规则 |
|---|---|
| 分析渠道 | 精确匹配 `大班型_渠道来源` |
| 当前期 | 1 个或多个 `学期期次`（趋势视图要求连续；不连续必须先向用户确认历史基准窗口）|
| 视图意图 | `达成` / `趋势` / `全部`（默认按用户提问主词推断；明确指明优先）|

## 路由原则
| 用户提问主词 | 路由 |
|---|---|
| 「达成 / 达标 / 完成度 / 缺口」 | 达成视图（不输出趋势）|
| 「趋势 / 变化 / 较前期 / 增长 / 下滑」 | 趋势视图（不输出达成判断）|
| 「招生整体怎么样 / 体检」或同时问两者 | 全部视图（先达成再趋势，两个 callout 分开）|

禁止：用户只问趋势时却套用达成视图导致输出「未达成 / 续报风险」混淆主线，反之亦然。

## 数据集与口径
- `market_sales_target`：L1 招生目标 / 续报人数目标 / 续报率目标（标内、L1招生目标 > 0）
- `market_sales_actual`：实际招生量 / 期内续报量
- 剔除班型：硬件体验课、新机器人体验课、其它测试、电销召回；排除 `2026春20期`
- 业务核算组缺失填 `其它`；`创新增长` 映射为 `内容营销`

## 期次口径
- **达成视图**：无历史基准；输入当前期就是目标对比窗口；多期整体加总判断，不逐期拆。
- **趋势视图**：历史基准窗口默认取当前窗口之前连续 N 个期次（N = 当前期数量）；两个窗口都整体加总后比较，不逐期拆。

## 核心指标
### 达成视图
| 指标 | 公式 |
|---|---|
| 招生差异 | `实际招生量 - L1招生目标`（正超额/负缺口）|
| 招生达成率 | `实际招生量 / L1招生目标`（聚合后重算）|
| 续报差异 | `期内续报率 - 续报率目标`（仅作风险提示）|

### 趋势视图
| 指标 | 公式 |
|---|---|
| 招生变化量 | 当前 - 历史 |
| 招生变化率 | 招生变化量 / 历史实际招生量 |
| 期内续报率变化 | 当前 - 历史（百分点）|
| 目标达成率变化 | 当前 - 历史（仅作相对预期参考，禁止输出达成判断）|

## 判断规则
### 达成视图
- `达成率 >= 100%` → 达成；`< 100%` → 未达成；目标缺失或 0 不输出判断。
- `期内续报率 < 续报率目标` → 提示续报质量风险（不改变达成判断）。

### 趋势视图
- `|变化率| <= 5%` → 小幅波动；`> 5%` → 需关注变化。
- 当前期内续报率高/低于历史 → 续报质量改善/走弱。
- **禁止**输出「达成/未达成」判断。

## 输出结构
### 达成视图
1. 结论 callout：咨询风格，一句话先判断达成/未达成，再说明主要缺口/超额来源 + 续报风险。
2. 核心数据对比支撑：≤ 3 条「判断 + 必要数字」证据句。
3. `业务核算组 + 定标渠道类型` 归因表图片：按 `L1招生目标` 降序，含 `总计` 行。

### 趋势视图
1. 结论 callout：咨询风格，先判断增长/下滑/持平，再说明影响程度、主要来源、续报质量变化、相对预期含义。**结论 callout 不展示数字**。
2. 核心数据对比支撑：≤ 3 条，固定三类证据句——**趋势强度句 / 来源集中度句 / 质量与预期句**；每条「4-8 字短判断标签 + 必要数字」，≤ 45 字。
3. 招生与续报变化表图片：按当前实际招生量降序，含 `总计` 行。
4. 目标达成率变化参考表图片：单独成表，避免主表过长。

### 全部视图
按「达成视图全部 → 趋势视图全部」顺序输出，两个 callout 独立，归因表 / 变化表都不省略。

## 数字展示规则
- 招生量 / 人数类：整数（可千分位）；禁止显示 `27,564.1`、`+50.9`。
- 达成率 / 续报率 / 变化率：聚合后原始分子分母重算，1 位小数 `%`。
- 续报率变化 / 目标达成率变化：1 位小数百分点。
- 红/绿字体：达成差异、招生变化量、续报率变化、目标达成率变化按方向标记。

## 归因表 / 变化表通用规则
- 末行 `总计`：人数加总；率/差异按汇总分子分母重算；禁止平均比例或差异。
- 输出图片，**不得**以 Markdown 表格作为最终归因表/变化表。
- 紧凑画布、咨询风格。

## 禁止输出
- 单独行动清单 / 无数据支撑的泛化建议。
- 渠道整体数据表格（整体数据只进入结论与核心证据句）。
- Markdown 表格作为归因表/变化表最终形态。
- 趋势视图中输出「达成/未达成」判断。
- 达成视图中输出历史趋势分析或独立趋势图。
- 「指标名：当前 X 历史 Y 变化 Z」事实罗列句。
