# L1 过程转化漏斗诊断

回答「续报率偏低是否由过程环节拖累」、「过程链路哪个环节出现问题」类问题；以连环替代法定位主拖累环节，再用 SKU 和渠道下钻验证。本 workflow 不重写漏斗算法，全部交由 `mth_l1_funnel_chain_substitution` 与 `mth_l1_flow_next_maturity_adjustment` 承载。

## 依赖的 method 资产
- `mth_l1_flow_next_maturity_adjustment` — 当存在当天有效的 `market_sales_actual_flow_adjusted` 缓存时，`期内续报量 / 完课转化率 / 期内续报率` 优先使用修正口径
- `mth_l1_funnel_chain_substitution` — 4 环节连环替代法，顺序固定 `加微率 → 加微首到率 → 首到留存率 → 完课转化率`

## 适用问题
- 某渠道过程转化、加微、到课、完课、完课转化或体验课链路表现。
- 续报率偏低是否由过程环节拖累，但未要求完整续报率结构归因。
- 招生达标但续报偏弱时，过程链路哪里出现问题。

## 不适用范围
- 不判断招生达成或未达成（走 `wf_l1_admission_diagnosis`）。
- 不替代 SKU 结构 / 智配-非智配结构 / 渠道组合续报率归因（走 `wf_l1_renewal_full_attribution`）。
- 不纳入 GMV、累计 GMV、客单价或续报价值诊断。

## 必要输入
| 输入 | 规则 |
|---|---|
| 分析渠道 | 精确匹配 `大班型_渠道来源` |
| 当前期 | 1 个或多个连续 `学期期次`，作当前窗口整体诊断 |
| 历史基准期 | 可选；未提供时默认取当前窗口之前连续 N 个期次 |

## 前置口径
- 必须先执行或确认 `mth_l1_flow_next_maturity_adjustment`
- 存在当天有效且覆盖两窗口的 `market_sales_actual_flow_adjusted` 时，`期内续报量 / 完课转化率 / 期内续报率` 优先使用修正口径
- 当前期不成熟且无法预测修正：只能分析前置过程，并在数据限制中标注 `期内续报率` 不可作为终局判断

## 固定指标（与 method 一致）
| 环节 | 名称 | 口径 |
|---|---|---|
| F1 | 加微率 | `微信添加量 / 实际招生量` |
| F2 | 加微首到率 | `首课到课量 / 微信添加量` |
| F3 | 首到留存率 | `4课完课量 / 首课到课量` |
| F4 | 完课转化率 | `期内续报量 / 4课完课量` |
| 结果 | 期内续报率 | `期内续报量 / 实际招生量` |

率类跨期次 / SKU / 渠道组合聚合时必须用聚合后分子分母重算。分母为 0 的环节必须标「不可验证」，**不得**硬算为 0 或 100%。

## 分析主线
1. **整体过程漏斗**：用 `mth_l1_funnel_chain_substitution` 判断哪个环节下降影响 `期内续报率`。
2. **全部 SKU 验证**：主拖累环节是否集中在某 SKU 或出现 SKU 间瓶颈分化。
3. **`业务核算组 + 定标渠道类型` 验证**：主拖累环节下降是渠道普降、单渠道放大还是多渠道共同拖累。**渠道下钻只服务环节验证**，不替代漏斗主因判断。

## 固定输出结构
```
整体结论
关键数据支撑
一、过程漏斗主因判断
二、SKU 层过程转化诊断
三、分 SKU 验证
口径说明
数据限制
```

## 图片要求
- **SKU 层过程转化总览**：保留全部 SKU，按当前实际招生量降序，追加 `总计` 行。
- **整体过程漏斗环节影响拆解**：按 `期内续报率影响` 绝对值降序；下降场景标记最大负向环节。
- **需要解释的 SKU 的过程漏斗环节影响拆解**：说明该 SKU 内主拖累环节。
- 对应 SKU 的 **`业务核算组 + 定标渠道类型` 下钻图**：按当前实际招生量降序，追加 `总计` 行；围绕该 SKU 主拖累环节展示变化贡献或负向贡献占比。

## 字段简洁原则
- SKU 总览只保留：当前招生量、历史/当前 `期内续报率`、`期内续报率变化`、`主拖累环节`。
- 渠道验证图只保留：当前招生量、被验证环节的历史/当前值、变化贡献、负向贡献占比、主拖累环节。
- **禁止**把四个漏斗环节的历史/当前值全部堆在同一张下钻图。
- 必须 PPT 可用咨询表格图片，**不能**用 Markdown 表格作为最终交付。

## 反面 case
- 未确认流入下一期成熟度直接解释期内续报率。
- 输出招生达成/未达成判断。
- 用 SKU 结构影响 / 智配-非智配结构影响 / 渠道组合总影响替代过程漏斗。
- 把渠道拆解作为主线，只回答「哪个渠道影响最大」。
- 渠道验证泛化为期内续报率渠道归因，而不是验证主拖累过程环节下降是否被渠道组合放大。
- 只列加微、到课、完课指标，不判断最大拖累环节。
- 使用 `首课到课承接率` / `4课完课承接率` 等旧命名。
- 对率类做算术平均。
- 把 GMV / 累计 GMV / 客单价作为主结论。
- 用 Markdown 表格替代图片表。
