# L1 渠道趋势图分析

基于已生成的渠道整体图与下钻图（PNG 文件），解读招生与续报率的图集化趋势。**不重新计算底层数据**，只做图片可视证据的咨询式判断。

## 适用问题
- 「xxx 渠道趋势」类查询。
- 指定 `大班型_渠道来源` 的招生与续报率趋势。
- 该渠道下 `业务核算组 + 定标渠道类型` 的招生与续报率趋势。

## 不适用范围
- 不重新计算底层招生 / 续报 / 目标数据。
- 不替代 `wf_l1_admission_diagnosis`、`wf_l1_renewal_full_attribution`、`wf_l1_process_funnel_diagnosis`。
- 不生成完整渠道扫描报告。
- 不推断图片不可见的信息。

## 必要输入
- 分析渠道：从「{分析渠道}渠道趋势」解析，精确匹配 `大班型_渠道来源`。
- 可选：日期（`YYYYMMDD`）。

## 日期与素材目录
素材根目录：`/jupyter/business-ops-scan/outputs/{日期}/招生续报分析/`

- **正式版本**：默认取当天；当天目录不存在必须申请执行 `市场渠道招生续报分析.ipynb` 生成素材；禁止自动回退历史日期。
- **测试过程**：当天目录不存在可回退最新可用日期目录，但必须在输出开头说明回退日期。

## 图片匹配
| 类型 | 路径 |
|---|---|
| 渠道整体图 | `{root}/{大班型_渠道来源}.png` |
| 下钻图目录 | `{root}/{大班型_渠道来源}/` |
| 下钻图 | `{root}/{大班型_渠道来源}/{业务核算组}-{定标渠道类型}.png` |

下钻图文件名以第一个 `-` 拆分：第一段 = 业务核算组，剩余 = 定标渠道类型。

禁用：
- 把 `{大班型}-{SKU}.png` 当渠道整体图。
- 读 `{大班型}/{SKU}/` 子目录的 SKU 图作下钻。
- 用 `智配进度`、`招生流向`、`团队对比` 等其它目录图片替代。

## 图片解读维度
同时解读：`实际招生量` 趋势 / `目标招生量` 或目标线状态 / `首日续报率` / `期内续报率`（续报质量主口径）/ `累计续报率` / `续报率S标` / 红色分割线提示的数据成熟度。

约束：
- 续报质量判断主口径固定为**成熟期次的 `期内续报率` vs `续报率S标`**。
- `首日续报率` `累计续报率` 仅作辅助走势。
- 成熟期 `期内续报率` 整体高于或贴近 S 标 → 必须写「达标或基本达标」。
- 红色分割线左侧最近一期 = 最近成熟期；右侧默认未成熟，不纳入达标判断。
- 看不清的数字不得编造；可描述方向性趋势但必须说明「图中数值不可清晰识别」。
- 每条结论最多 3 个关键数值或方向判断，避免逐期复述。

## 输出结构
1. **整体来看**（放第一位）：咨询式全局结论，先判断整体走势、再点主要分化和经营含义；不在此处写未成熟期风险提示。
2. **口径补充说明**（仅当识别出未成熟期次时）：固定格式 `口径补充说明：{未成熟期次} 未成熟，分析中未纳入；续报率判断以成熟期次的期内续报率对比S标为准。`
3. **渠道趋势分析**：图集排版，每排 3 张图；先渠道整体，再下钻；下钻按最近成熟期 `实际招生量` 降序。

每张图下方备注格式：`渠道名称：结论内容`。
- 渠道整体卡片名称固定 `渠道整体`。
- 下钻卡片名称固定 `业务核算组 / 定标渠道类型`，禁用 `+`（如 `线上BD / 外呼-9元`，非 `线上BD + 外呼-9元`）。
- 备注必须同时覆盖招生趋势和续报率趋势。
- 去掉「数据依据 / 核心依据」段落。

## 缺失素材处理
- 整体图缺失：列出缺失路径，不生成整体趋势结论。
- 下钻图缺失：列出缺失路径或说明无下钻素材，不编造下钻结论。

## 禁止输出
- 数据依据段落、底层数据重算表、目标达成/未达成诊断、历史窗口归因表、独立行动清单、无图片支撑的泛化建议。
- `9.9常规 渠道整体趋势` / `业务核算组 + 定标渠道类型趋势` 这类二级分层。
- 把 SKU 图片作为渠道整体趋势图。
