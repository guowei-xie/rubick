# L1 GMV达成归因（三因子序贯分解）

视角：市场（view=market）。用于「GMV 是否达标 + 缺口由谁主导」，把 GMV 缺口按招生量/续报率/客单价三因子序贯分解并闭合，再对关键缺口渠道做结构下钻。

## 步骤

### 1. 定场景 · 达成体检
确认指标=GMV、基准=对目标、视角=市场、单期/多期。达成口径优先用**可用 GMV**：成熟期次取观测期内 GMV；不成熟期次取预测修正后期内 GMV（`mth_l1_flow_next_maturity_adjustment`，成熟度修正仅市场侧）。取 `mq_l1_gmv_target` 与可用 GMV，算缺口与 `mq_l1_gmv_achievement_rate`（实际/目标，<100% 标红）。

### 2. 三因子序贯分解（`mth_l1_gmv_three_factor_decomposition`）
将 GMV 缺口依次替代分解为：
- 招生量影响 = `mq_l1_gmv_impact_admission`
- 续报率影响 = `mq_l1_gmv_impact_renewal_rate`（机制：实际续报率低于 S 标）
- 客单价影响 = `mq_l1_gmv_impact_arpu`（客单价基于 `mq_l1_arpu_actual`）

续报口径用 `mq_l1_corrected_inrenewal_gmv`（修正后期内续报 GMV）。三因子求和须**精确闭合**于 GMV 缺口；率类先汇总分子分母再相除。

### 3. 关键因子定性
负向取 TOP2、正向取 TOP1，用「状态词+占比%」定性主因；占比 2 位小数、按 %。禁把单点异常写成高权重放大。

### 4. 关键缺口渠道下钻（`mth_l1_structural_attribution`）
对主因因子（如续报率影响）所在的最大缺口渠道做中心化结构归因：结构影响 `(w1−w0)(r0_group−r0_parent)` + 率影响 `w1(r1−r0)`，Σ 闭合于该渠道缺口。基期率按维度真实取数、不用父级兜底。不得仅拆最大渠道——须覆盖负贡献群体逐行核对。

### 5. 可执行建议
对象+动作+预期，只放数据支持的因果，不外推预测。

## 输出
1. GMV 达成整体结论（一句话定性）
2. 三因子分解表（招生量/续报率/客单价影响，Σ 闭合，含总计行）
3. 关键缺口渠道下钻（结构归因，闭合）
4. 可执行建议

## 护栏
- 问 GMV 只拆 GMV 三因子，归因对象须对齐所问指标，不换续报三因子。
- 三因子须闭合于 GMV 缺口。
- 市场侧不成熟期取修正后期内 GMV，未修正不得直接判达成。
- 单一数据源闭合，不跨源拼接。
