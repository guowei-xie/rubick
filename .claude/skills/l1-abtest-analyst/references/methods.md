# 分析方法

## AB实验设计与样本量功效测算（mth_ab_experiment_design_power）

在实验上线**前**确定分流单位、指标体系、样本量与实验时长；也用于事后判断「不显著」到底是真无效果还是功效不足。任何 AB 测试类诉求，先过这张卡再谈读数。

## 1 分流单位与分析单位必须一致
- 分流单位（randomization unit）候选：用户 / 订单 / 班级组 / 期次×渠道 / 城市 / 班主任
- **铁律：分析单位 ≤ 分流单位**。按用户分流却按订单算率 → 同一用户多单强相关，方差被低估、p 值虚假显著。若必须错位，二选一：① 先聚合到分流单位再算；② 用按分流单位聚类的稳健标准误（cluster-robust SE）。
- 存在溢出 / 干扰（同班同学互相影响、同一班主任同时服务两组、同城市共享供给）→ 分流单位上提到班级组 / 班主任 / 城市，不要按用户分。

## 2 指标分层（设计期定死，禁止事后挑）
| 层级 | 作用 | 数量约束 |
|---|---|---|
| 核心指标（OEC） | 唯一决策依据 | 1 个，最多 2 个 |
| 护栏指标 | 不能变差的底线（退费率、投诉、客单价、人效） | 3–5 个 |
| 次要 / 诊断指标 | 解释机制，不参与上线决策 | 不限 |

**事前登记**：核心指标、预期方向、显著性水平 α、目标功效、样本量、停止规则，必须在开跑前写下来。读数阶段更换核心指标 = 结论作废。

## 3 样本量公式
双样本比例（双尾）：
```
n_per_group = (z_{1-α/2} + z_{1-β})^2 * [p1*(1-p1) + p2*(1-p2)] / (p2 - p1)^2
```
双样本均值（等方差）：
```
n_per_group = 2 * (z_{1-α/2} + z_{1-β})^2 * σ^2 / δ^2
```
非等分流（n2 = r*n1）时，比例场景修正为：
```
n1 = (z_{1-α/2} + z_{1-β})^2 * [p1*(1-p1) + p2*(1-p2)/r] / (p2-p1)^2
```
默认 α = 0.05、power = 0.8；影响上线/预算的关键决策用 power = 0.9。

## 4 MDE 从业务反推，不要从数据凑
MDE（最小可检测效应）= **值得为之改代码 / 改流程 / 追加预算的最小提升**。先问业务方「提升多少你才会上线」，再算样本量。

样本量不够时的**合法**出路：延长实验期、放大实验流量占比、换低方差指标（CUPED 方差缩减、用连续型代理指标替代稀疏转化）、接受更大的 α 并在报告中明示。
**不合法**：偷偷把 MDE 调大到刚好够用，然后宣称"实验设计充分"。

## 5 实验时长
- 至少覆盖 **1 个完整业务周期**。L1 体验课场景 = 一个完整期次（term），从招生开始到续报窗口关闭。
- 有新奇效应 / 学习效应的功能，前 3–7 天数据单独观察，不直接并入总体读数。
- 结论口径含滞后指标（续报、退费、完课）时，实验期必须 ≥ 该指标的成熟窗口；否则只能读"未成熟观测值"，并在报告中显式标注成熟度与观察截止日。

## 6 事后功效（post-hoc power）是错误做法
结果不显著时，**禁止**用观测到的效应量反算 power 说"功效不足"——这是循环论证（观测效应越小算出的 power 必然越低）。

正确做法是报告效应量的置信区间：
- CI 完全落在 [-MDE, +MDE] 内 → 可以说"已排除业务上有意义的效果"（等价检验思路）
- CI 跨过 ±MDE → 只能说"本实验无法判定"，不能说"无效果"

## 7 整群分流的样本量必须乘设计效应
按老师组 / 班级组 / 城市这类**群**分流时，同群内个体高度相关，订单数远不等于有效样本量：
```
DEFF = 1 + (m - 1) * ICC          # m = 群平均规模，ICC = 组内相关系数
n_需要 = n_个体公式结果 * DEFF
有效样本量 = 实际个体数 / DEFF
```
续报率这类强受老师影响的指标 ICC 常在 0.01–0.05，m = 500 时 DEFF 可达 6–26 倍。**设计阶段就要按群数而非个体数规划**：群数不够，个体再多也做不出功效。群数 < 30 时聚类标准误的渐近性质失效，需 wild cluster bootstrap；< 10 时不要承诺能得出推断结论。

ICC 用历史同类数据估（见《准实验设计选型与证伪检查》的 `estimate_icc`），拿不到就取行业保守值 0.02 并在报告中标注为假设。

## 常见坑
- 多变体（A/B/C/D）却按两组算样本量 → 必须先定多重比较校正方式，再按校正后的 α 算
- 用历史全量方差估 σ，但实验人群是子集 → σ 偏大，样本量虚高，白等
- 分流比例非 50/50 却套等分公式 → 少数组功效严重不足
- 只算了核心指标的样本量，护栏指标（低频事件如退费）远未达到可检测量 → 护栏"没变差"其实是查不出来
- 按老师组/班级组分流却按订单数算样本量 → 漏乘 DEFF，功效严重高估，几乎必然得出假显著或假无效

## AB实验读数与统计推断规范（mth_ab_readout_inference）

实验跑完后的**读数与统计推断**规范：先做有效性校验，再按指标类型选检验方法，最后用置信区间而非 p 值下结论。校验不通过的实验一律不读数。

## 1 读数前的三道有效性校验（任何一条不过 → 停止读数）

**① SRM（Sample Ratio Mismatch，分流比例失衡）**
```
卡方检验：χ² = Σ (observed_i - expected_i)^2 / expected_i，df = k-1
```
p < 0.001 即判定 SRM 异常。**SRM 是分流或日志故障的信号，不是随机波动**——出现即停止读数，回查分流逻辑、埋点丢失、过滤条件是否作用于处理后变量。

**② AA 校验 / 基线协变量均衡**
对实验期**之前**的历史指标与关键协变量（城市线级、支付年级、渠道类型、期次、班型）逐一比对两组分布。允许个别维度偶然不均衡（多重比较下必然发生），但核心指标的历史基线显著不同 → 分流有问题。

**③ 过滤条件不得作用于处理后变量**
只能用**实验开始前**已确定的字段做过滤（人群、渠道、期次）。用实验后产生的行为（如"仅看已进班用户"）切分样本 = 对撞偏差，结论作废。这是最隐蔽也最常见的错误。

## 2 按指标类型选检验方法
| 指标类型 | 例子 | 推荐方法 | 禁止 |
|---|---|---|---|
| 比例 / 转化率 | 进班率、续报率、退费率 | 双样本比例 z 检验；小样本用 Fisher | 对行级 0/1 求平均后做 t 检验并按原始行数算自由度 |
| 均值（连续） | 客单价、GMV per user | Welch's t（默认不假设等方差） | 默认 Student t |
| 重尾 / 有极端值 | GMV、退费金额 | 分位数处理 + bootstrap CI；或 log 变换后读相对效应 | 直接均值 t 检验后忽略长尾 |
| **比率型**（分子分母都是随机量） | 人均完课节数、单均 GMV、率的率 | **Delta method** 或 bootstrap（按分流单位重抽样） | 直接把比率当均值做 t 检验 |
| 计数 | 订单数、发消息条数 | 泊松 / 负二项回归（过离散时必须用负二项） | 泊松 + 过离散共存 |

**比率型 delta method 方差**（X/Y，按分流单位聚合后）：
```
Var(X/Y) ≈ (1/Ȳ²)·Var(X) - 2·(X̄/Ȳ³)·Cov(X,Y) + (X̄²/Ȳ⁴)·Var(Y)
```

## 3 方差缩减：CUPED（有历史数据时默认启用）
```
Y_adj = Y - θ·(X - X̄)，  θ = Cov(Y, X) / Var(X)
方差缩减比例 = ρ²(Y, X)
```
X 必须是**实验前**的协变量（同一指标的实验前取值最有效）。ρ = 0.5 时方差降 25%，等价于样本量放大 1.33 倍。CUPED 不改变效应量的期望，只降方差——**若 CUPED 前后效应量大幅变化，说明分流不均衡，回查第 1 节**。

## 4 多重比较
- 多个变体 / 多个核心指标 / 多次中途查看，都会抬高假阳性率
- 少量对比（≤5）→ Holm-Bonferroni；大量指标（诊断层）→ Benjamini-Hochberg 控制 FDR
- 护栏指标**不做**校正（宁可假阳性也不能漏掉恶化）
- 中途反复看数据要用序贯检验（always-valid CI / group sequential），否则每看一次就多一次假阳性机会

## 5 下结论：置信区间优先于 p 值
报告格式固定为：**效应量 + 95% CI + 相对提升 + p 值**，四者齐全。

判定规则（MDE 来自设计期，见「AB实验设计与样本量功效测算」）：
- CI 下界 > 0 且下界 > MDE → 有效且有业务价值，建议上线
- CI 下界 > 0 但上界 < MDE → 统计显著但业务无意义，不建议为此付出成本
- CI 完全在 [-MDE, MDE] 内 → 已排除有意义效果，可判定为"无差异"
- CI 跨过 ±MDE → 无法判定，说清楚需要多少样本才能判定

**禁止表述**："p = 0.06，接近显著，有上升趋势"；"实验组更高（未标注 CI）"；"无显著差异所以两者一样"。

## 6 分群下钻的纪律
整体不显著时逐个子群找显著 = p-hacking。子群分析只在两种情况下可信：① 事前登记的假设；② 用交互项检验异质性显著后再拆。任何探索性子群结论必须标注"**探索性发现，需独立实验验证**"。


**可执行脚本**（推荐依赖：scipy>=1.10, numpy>=1.24, pandas>=2.0）：调用 `python3 methods/run.py mth_ab_readout_inference '<params_json>'`；参数 schema 见 `methods/mth_ab_readout_inference.json`。**不要手写参数化、不要重新生成代码。**

## 准实验设计选型与证伪检查（mth_quasi_experiment_designs）

当**无法随机分流**（策略已全量上线、按城市/期次整体铺开、历史事件回溯、伦理或成本不允许随机）时的设计选型与证伪检查。核心问题永远是同一个：**对照组凭什么代表处理组没被干预时会发生什么**。

## 0 选型决策树
```
有干预前后 + 有可比未干预组 + 干预前趋势平行 ──→ DID（双重差分）
  └ 只有 1 个处理单元、有多个候选对照单元 ────→ 合成控制（SCM）
  └ 处理时点不同（分批铺开）───────────────→ 交错 DID（用 CS / SA 估计量，不用双向固定效应）
按班主任组/老师组投放，对照取同班型大盘 ──→ DID（首选）/ 老师组层面 PSM；见 §7
按连续变量阈值分配（分数≥X 才给） ─────────→ RDD（断点回归）
只有处理组、有长时间序列、干预时点明确 ────→ ITS（中断时间序列）
可观测协变量能解释分配机制（选择在可观测项上）→ PSM / IPW / 双重稳健
存在只影响分配、不直接影响结果的外生变动 ──→ IV（工具变量）
以上都不满足 ──────────────────────→ 只做相关性描述，明确写「不可做因果解释」
```

## 1 DID（双重差分）
```
ATT = (Y_treat,post - Y_treat,pre) - (Y_ctrl,post - Y_ctrl,pre)
回归式：Y = β0 + β1·treat + β2·post + β3·(treat × post) + γ·X + ε，ATT = β3
```
- **标准误必须按处理单元聚类**（cluster by 城市/期次/班级组）。不聚类 → 严重低估标准误，几乎必然假显著。处理单元 < 30 个时用 wild cluster bootstrap。
- **平行趋势是必须证伪的假设，不是可以口头声明的前提**：至少 3 个干预前周期做事件研究图（event study），所有 pre 期系数应不显著且无趋势。
- 交错处理（不同单元不同时点上线）**禁止**直接用双向固定效应 TWFE——已被证明会用"已处理组"当对照产生负权重，符号都可能反。改用 Callaway–Sant'Anna 或 Sun–Abraham 估计量。

## 2 合成控制（SCM）
处理单元只有一个（如"只在杭州试点"）时，用多个未处理单元的加权组合拟合处理前的处理单元轨迹。
- 权重非负且和为 1，禁止外推
- 效果显著性靠**安慰剂检验**：把每个对照单元轮流当作"伪处理单元"跑一遍，看真实处理效应是否落在分布尾部
- 干预前拟合期至少 10 个周期；拟合 RMSPE 过大 → 不可用

## 3 RDD（断点回归）
分配由连续变量是否越过阈值决定（如"城市评分 ≥ X 才投放"）。
- 只识别**阈值附近**的局部效应（LATE），不要外推到全体
- 必检：① 密度检验（McCrary）——运行变量在阈值处密度跳跃 = 有人操纵分配，RDD 失效；② 协变量连续性——其他变量在阈值处不应跳跃；③ 带宽敏感性——换几个带宽结论应稳定
- 用局部线性回归 + 三角核，**不要**用高阶多项式全局拟合

## 4 ITS（中断时间序列）
```
Y_t = β0 + β1·t + β2·D_t + β3·(t - t0)·D_t + ε_t
β2 = 水平跳变（即时效应），β3 = 斜率变化（持续效应）
```
- 干预前至少 8–12 个周期；必须处理自相关（Newey-West / ARIMA 残差）与季节性
- **没有对照组 = 无法排除同期其他变化**（大促、政策、竞品）。必须列出同期事件清单，能加对照序列就升级为 controlled ITS

## 5 PSM / IPW / 双重稳健
基于可观测协变量重建可比性。**只在"选择发生在可观测项上"成立时有效**——这个假设不可检验，必须靠业务论证。
- 倾向得分只放**干预前**变量；放入处理后变量 = 对撞偏差
- 匹配/加权后必检**协变量均衡**（标准化均值差 SMD < 0.1）与**共同支撑**（重叠区域），不达标就重做
- 权重极端（IPW 中 e(X) 接近 0 或 1）→ 截断（trimming）或改用重叠权重
- 首选**双重稳健**（AIPW / TMLE）：倾向得分模型与结果模型有一个对就一致

## 6 IV（工具变量）
工具需同时满足：① 相关性（第一阶段 F > 10，否则弱工具，2SLS 偏差比 OLS 还大）；② 外生性；③ 排他性约束（只通过处理影响结果）。②③ 不可检验，必须靠制度背景论证——**没有可信论证就不要用 IV**。识别的是"依从者"局部效应（LATE）。

## 7 交付前的统一证伪清单
每个准实验结论都要附以下四项，缺一不可：
1. **识别假设是什么**，以及为什么在本场景成立（一句话业务论证）
2. **安慰剂检验**：假处理时点 / 假处理单元 / 不该受影响的结果变量，都应无效应
3. **稳健性**：换对照组、换窗口、换带宽、换模型设定，结论方向不变
4. **残余混杂的方向判断**：如果假设被违反，偏差会让效应被高估还是低估

## 7 班主任组为单位的销售SOP类准实验（公司最常见形态）

公司的准实验绝大多数是这个形态：某套销售 SOP / 话术 / 跟进节奏，先在若干**班主任组（老师组）**试点，其余照旧；对照组默认取「**相同定标班型（`goal_class_tag`）下的大盘**」。它同时踩中整群设计、非随机分配、对照组包含处理组三个坑，按下面的顺序处理。

### 7.1 对照组必须先剔除实验组
大盘 = 全部老师组，天然包含试点组。不剔除 → 对照组被处理效应污染，估计值系统性**低估**。
```sql
-- 对照组口径：同定标班型大盘，剔除实验组老师组
WHERE goal_class_tag IN (<本次投放的班型>)
  AND renewal_counselor_group_id NOT IN (<实验组老师组清单>)
```
剔除后要报一次两组的老师组数与订单数，让读者看到对照池规模。

### 7.2 有效样本量 = 老师组数
整群设计的方差由**组间方差**主导，订单数再多也不能等价于样本量。设计效应：
```
DEFF = 1 + (m - 1) * ICC        # m = 每组平均订单数，ICC = 组内相关系数
有效样本量 ≈ 实际订单数 / DEFF
```
续报率这类受老师影响大的指标，ICC 常在 0.01–0.05；m = 500 时 DEFF 可达 6–26 倍，即十万订单的有效样本量可能只相当于几千。**先算 DEFF 再谈显著性**，否则必然假显著。

### 7.3 标准误按老师组聚类，组数少时用 wild bootstrap
`cluster = renewal_counselor_group_id`（或用户给的组标识）。老师组数 < 30 → 渐近聚类 SE 失效，用 wild cluster bootstrap。组数 < 10 时任何推断都极不稳，只能做描述并明确说明。

### 7.4 选择偏差：试点组不是随机挑的
试点组通常是配合度高 / 业绩好 / 基地便于管理的组，本身就与大盘不可比。必查基线：
历史续报率、`goal_class_tag` 班型结构、`term_id` 期次结构、`is_new_renewal_staff` 新人占比、`renewal_counselor_group_city` 基地分布、组规模（人均带班量）。

处理顺序：① 有干预前多期数据 → **DID + 事件研究验平行趋势**（首选）；② 只有横截面 → 老师组层面 PSM / 熵平衡，匹配后查 SMD < 0.1；③ 试点组只有 1–2 个 → **合成控制**，用其余老师组加权拟合。

### 7.5 SOP 溢出会稀释效应
话术在老师之间口口相传，同基地 / 同团队的对照组老师可能自发采用 → SUTVA 违反，效应被低估。缓解：对照组限制在不同基地（`renewal_counselor_group_city`）或不同团队（`goal_operation_group`）；或在报告中标注「本估计为效应下界」。

### 7.6 时间窗与老师流动
- 名单必须带**生效期次 / 生效日期**。实验组老师在生效前的订单属于干预前，是 DID 的基期，不能算进处理组。
- 老师在实验期内转组 / 离职 / 新人入组 → 按**意向处理（ITT，按名单初始归属）**为主口径，另报一版剔除流动样本的稳健性结果。
- 结果指标是续报时，实验期必须覆盖完整续报窗口；未成熟就读数会把「还没到时间」误判为「SOP 无效」。

### 7.7 本形态的报告必写项
实验组老师组数与订单数、对照组（剔除后）老师组数与订单数、ICC 与 DEFF、聚类方式、平行趋势检验结果、基线均衡表、溢出风险判断与效应方向。

## 与随机实验的关系
准实验的证据等级**低于**随机实验。凡是能随机的就随机；用准实验时，报告必须显式写出证据等级与关键假设，禁止把准实验估计当作与 AB 实验同等强度的结论。

## 因果识别清单与偏差排查（mth_causal_identification_checklist）

在选定任何估计方法**之前**先跑一遍的识别清单。作用是回答两个问题：**这个数能不能做因果解释？如果不能，还能说什么？** 相关性分析本身没错，错的是把它当因果结论交付。

## 1 先画因果图，再选变量
用 DAG 把「处理 T → 结果 Y」路径上的变量分三类，处理方式完全不同：

| 变量类型 | 定义 | 正确处理 | 错误处理的后果 |
|---|---|---|---|
| **混杂**（confounder） | 同时影响 T 和 Y | **必须**控制 | 不控制 → 效应有偏 |
| **中介**（mediator） | 在 T 之后、传递 T 的效应 | 估总效应时**不控制** | 控制 → 把真效应吸走，低估甚至消失 |
| **对撞**（collider） | 同时被 T 和 Y 影响 | **绝不**控制、绝不据此筛样本 | 控制/筛选 → 凭空造出虚假关联 |
| 前置代理 | 只影响 Y、与 T 无关 | 可控制（降方差） | 无害，提升精度 |

**一条可操作的铁律：只用干预发生之前就已确定的变量做控制与筛选。**任何"实验后才知道"的字段（是否进班、是否加微、是否完课）既不能当协变量，也不能当过滤条件。

## 2 识别假设与可检验性
| 假设 | 含义 | 可检验？ | 违反时怎么办 |
|---|---|---|---|
| 可交换性 / 无未观测混杂 | 控制协变量后分配与潜在结果独立 | **不可检验** | 业务论证 + 敏感性分析 |
| 正值性 / 共同支撑 | 每个协变量取值下两组都有样本 | 可检验（重叠图） | 截断样本，缩小推断人群并说明 |
| SUTVA | 个体潜在结果不受他人处理影响 | 部分可检验 | 上提分流/分析单位 |
| 一致性 | 处理定义明确、版本唯一 | 靠定义 | 明确写清「处理到底是什么」 |

## 3 SUTVA 与干扰：教育业务的高频陷阱
- 同班同学、同一个班主任、同一个家长社群 → 处理会外溢到对照组，效应被稀释（低估）
- 供给侧共享（班主任精力、名额、库存）→ 实验组多拿一份，对照组就少一份，效应被放大（高估）
- 判定方式：看对照组在实验期的指标是否偏离其历史轨迹；有偏离即存在干扰
- 处理方式：整群随机（按班级组/校区/城市分流）、或缓冲带隔离，并在报告中标注干扰方向

## 4 选择偏差自查（分析样本是怎么来的）
- 样本筛选条件里有没有处理后变量？（见第 1 节铁律）
- 有没有幸存者偏差？（只看留下来的用户 → 退费/流失被系统性剔除）
- 有没有差异化缺失？（实验组埋点覆盖率与对照组不同 → 直接产生 SRM 类偏差）
- 时间窗口是否对两组同等成熟？（后进组的滞后指标天然更低）

## 5 异质处理效应（HTE）
平均效应为零不等于对谁都无效。但子群探索极易 p-hacking，纪律是：
1. **先做交互项检验**：整体模型加 `T × 子群维度`，交互显著才有资格拆
2. 大量维度时用因果森林 / meta-learner（T/S/X-learner）估条件效应，再对识别出的高响应群体做**独立验证实验**
3. 任何未事前登记的子群结论，一律标注「**探索性发现，需独立验证**」，不进决策结论区

## 6 敏感性分析（无未观测混杂假设的兜底）
不能证明没有未观测混杂，但可以量化「需要多强的混杂才能推翻结论」：
- **E-value**：把观测到的效应解释掉，所需的未观测混杂与 T、Y 的最小关联强度
- Rosenbaum bounds（匹配设计）；Oster δ（基于可观测混杂的选择程度外推）
- 结论：E-value 远大于任何合理的现实混杂强度 → 结论稳健；接近 1 → 结论脆弱，必须在报告中降级表述

## 7 结论语言分级（强制）
| 证据 | 允许的表述 |
|---|---|
| 随机实验 + 校验通过 | 「X 导致 Y 提升 a%（95% CI …）」 |
| 准实验 + 假设证伪通过 | 「在【假设】成立的前提下，X 使 Y 提升约 a%；关键风险是【…】」 |
| 仅控制可观测混杂 | 「控制【变量清单】后仍观察到 a% 差异；不排除未观测混杂」 |
| 纯观测相关 | 「X 与 Y 相关（相关系数 …）；**本分析不支持因果解释**」 |

**禁止**：在纯相关分析里使用「带来」「拉动」「驱动」「贡献了」「因为…所以」等因果动词。

## 实验组间基础聚合概览表（mth_experiment_group_overview）

**任何组间对比的第一步。**拿到分组名单后、做任何统计检验之前，先出这张基础聚合概览表。它同时承担三个作用：把两组摆在同一张表上看规模是否可比、沿漏斗定位差异发生在哪一跳、为《实验组间可比性审查清单》的 CK-01（人效差异）与 CK-04（组规模）提供数据入口。

## 固定字段与口径

窗口统一取**期内口径**（`_t6` 后缀）。`_t0` 是首日内口径，只在明确要看首日转化时才用，两者不可混用。

| 列 | 口径 | 表达式（订单表） |
|---|---|---|
| 组别 | 实验组 / 对照组，由分组名单决定 | 按名单映射 `counselor_id` |
| CT数 | 老师去重数 | `count(distinct counselor_id)` |
| 用户量 | 用户去重数 | `count(distinct user_id)` |
| 平均人效 | 每位老师平均带的用户量 | `用户量 / CT数` |
| 加微率 | 加微用户占比 | `sum(wx_add) / 用户量` |
| 加微/首到 | 加微→首课到课的下一跳转化 | `sum(attend1_t6) / sum(wx_add)` |
| 首课到课率 | 首课（1课）到课占比 | `sum(attend1_t6) / 用户量` |
| 三课完课率 | 3课完课占比 | `sum(finish3_t6) / 用户量` |
| 留存率 | 三课完课 / 首课到课 | `sum(finish3_t6) / sum(attend1_t6)` |
| 完转率 | 期内续报率 / 三课完课率 | `sum(renewal_lst) / sum(finish3_t6)` |
| 续报率 | 期内续报率 | `sum(renewal_lst) / 用户量` |

**字段映射说明（已核对表元数据，不要凭名字改写）**：
- `attend1_t6` = 是否1课到课。**注意 `attend0_t6` 是「准备课到课」，不是首课**——表里「首课」与「准备课」是两个概念（另有 `attend0_ahead_unlocked1` = 首课解锁前准备课到课佐证）。误用会让首课到课率虚高。
- `finish3_t6` = 是否3课完课（`finish0` 为准备课完课）
- `renewal_lst` = 末日续报，即**期内**续报口径。`renewal_acc` 是全局累计续报（含跨期后续），口径更大，不要混用
- `counselor_id` = 老师id；销售 SOP 若考察的是续报环节执行人，改用 `renewal_staff_id` 并在表头注明

**留存率与完转率的简化**：两者的分子分母同源于订单级标记，可直接用计数相除，等价于「率÷率」。写成计数比更不容易出错。

## 计算铁律

1. **率一律先聚合再相除**：`率 = sum(分子) / sum(分母)`。禁止对行级率求平均、禁止 `sum(rate)`。
2. **分母为零要兜住**：所有比值用 `nullif(分母, 0)` 保护，避免整行报错。
3. **粒度一致性强制校验（最容易算错的一处）**：分子 `wx_add` / `attend1_t6` / `finish3_t6` / `renewal_lst` 都是**订单级** 0/1 标记，而「用户量」是 `user_id` 去重。同一用户有多笔订单时，分子分母粒度不一致，率会虚高。
   ```
   先跑一次：count(order_no) vs count(distinct user_id)
   两者差异 > 1% → 必须先定粒度：要么分母改 count(order_no) 统一到订单级，
                    要么先把订单去重到用户级再算分子。不要带着差异往下走。
   ```
   差异比例本身也要报出来，两组分别报——**如果两组的重复下单程度不同，这本身就是一条可比性问题**。

## 参考 SQL（DuckDB 方言）

```sql
WITH base AS (
  SELECT
    CASE
      WHEN counselor_id IN (<实验组老师ID清单>) THEN '实验组'
      WHEN counselor_id IN (<对照组老师ID清单>) THEN '对照组'
    END AS grp,
    order_no, user_id, counselor_id,
    wx_add, attend1_t6, finish3_t6, renewal_lst
  FROM ba_eda_l1_v2_info_order_hdf
  WHERE dt = '<分区日期>'
    AND term_id IN (<实验期次>)
    AND goal_class_tag IN (<定标班型>)
)
SELECT
  grp                                                              AS 组别,
  count(DISTINCT counselor_id)                                     AS CT数,
  count(DISTINCT user_id)                                          AS 用户量,
  count(order_no)                                                  AS 订单数,
  count(DISTINCT user_id) * 1.0
    / nullif(count(DISTINCT counselor_id), 0)                      AS 平均人效,
  sum(wx_add) * 1.0      / nullif(count(DISTINCT user_id), 0)      AS 加微率,
  sum(attend1_t6) * 1.0  / nullif(sum(wx_add), 0)                  AS 加微首到,
  sum(attend1_t6) * 1.0  / nullif(count(DISTINCT user_id), 0)      AS 首课到课率,
  sum(finish3_t6) * 1.0  / nullif(count(DISTINCT user_id), 0)      AS 三课完课率,
  sum(finish3_t6) * 1.0  / nullif(sum(attend1_t6), 0)              AS 留存率,
  sum(renewal_lst) * 1.0 / nullif(sum(finish3_t6), 0)              AS 完转率,
  sum(renewal_lst) * 1.0 / nullif(count(DISTINCT user_id), 0)      AS 续报率
FROM base
WHERE grp IS NOT NULL
GROUP BY grp
ORDER BY grp
```

对照组走「同定标班型大盘」默认口径时，`WHEN ... THEN '对照组'` 改为
`WHEN counselor_id NOT IN (<实验组老师ID清单>) THEN '对照组'`——**大盘必须剔除实验组本身**，否则效应被稀释。

## 怎么读这张表（顺序固定）

1. **先看 CT数 / 用户量 / 平均人效** —— 判断两组够不够可比。人效差距明显 → 触发 CK-01，**不要继续做整体均值对比**，先定位差距来自量还是率
2. **再看规模** —— CT数就是有效样本量（不是用户量）。CT数 < 30 时后续推断要用 wild cluster bootstrap，< 10 时只做描述
3. **再沿漏斗逐跳看** —— 加微率 → 加微/首到 → 首课到课率 → 三课完课率 → 留存率 → 完转率 → 续报率。找出**两组差异最大的那一跳**，那才是 SOP 真正起作用（或出问题）的环节
4. **最后看终点指标** —— 续报率差异若与中间各跳差异对不上（如各跳都持平但续报率差很多），说明有未纳入的因素，别急着归因给 SOP

## 输出规范
- 率列百分号保留 1 位；平均人效保留 1 位小数；CT数 / 用户量 / 订单数为整数
- 两组之外固定加一行**差值行**（实验组 − 对照组），率差用 `pp`
- 这张表是描述性的，**本身不构成结论**。任何显著性判断都要走《AB实验读数与统计推断规范》或《准实验设计选型与证伪检查》

## 实验组间可比性审查清单（mth_experiment_comparability_checks）

**本卡是活文档。**每条 = 一个可判定的组间可比性审查项。角色在实际分析中被用户提醒、或自己发现新的注意事项时，按本卡末尾的「沉淀协议」以反馈形式追加条目，让下一次同类实验能直接复用。

**使用时机**：拿到分组名单之后、给出任何效应量之前，逐条过一遍。过检结果写进报告的「有效性校验」段。**未过检的项必须在报告局限中列出**，不能默默跳过。

**适用范围**：以班主任组 / 老师组为单位的准实验（销售 SOP 类测试为主），以及任何非随机分组的组间对比。随机 AB 实验只需过 CK-08、CK-10。

## 审查清单

### CK-01 人效差异（两组老师人效差距大时禁止直接对比）
- **触发**：实验组与对照组的人均产出（人均招生量 / 人均续报量 / 人均 GMV）差距明显
- **为什么**：人效差异说明两组老师本身能力或资源就不同，直接比较组间结果指标，测到的是「老师差异」而不是「SOP 效应」
- **怎么判**：先算两组人效，再把差距拆开定位来源——
  ```
  人均产出 = (订单量 / 老师数) × 转化率
  差距拆解顺序：① 组规模与带班量差异 → ② 单人接单量差异 → ③ 单人转化率差异
  ```
  拆到能说清「差距主要来自量还是来自率」为止
- **不通过怎么办**：**不做整体均值对比**。改用：① 老师组层面 PSM / 熵平衡匹配人效相近的组；② DID 只看「变化量」而非「水平值」（人效差异会被组固定效应吸收）；③ 按人效分层后组内对比。三选一，并在报告中写明选择理由

### CK-02 线索结构组成一致性
- **触发**：任何组间对比，默认必查
- **为什么**：两组拿到的线索结构不同（渠道占比、班型占比、期次分布、城市分布），结果差异可能全部来自结构而非 SOP
- **怎么判**：对 `goal_channel_type`（定标渠道类型）、`goal_class_tag`（定标班型）、`analysis_class_tag`（分析用班型）、`term_id`（期次）、`renewal_counselor_group_city`（基地）逐维做两组占比对比；连续型协变量用标准化均值差 SMD < 0.1，类别型看占比差与卡方
- **不通过怎么办**：① 把失衡维度作为协变量进模型；② 分层分析后加权汇总；③ 结构差异过大时缩小对比范围到共同支撑区间，并明确说明推断人群已缩小

### CK-03 线索质量一致性
- **触发**：任何组间对比，默认必查。结构一致**不等于**质量一致
- **为什么**：同一渠道、同一班型下，线索质量仍可能系统性不同（试点组常被优先分配优质线索）
- **怎么判**：比对两组的质量代理变量——`pay_grade` / `package_grade`（支付/包年级）、`city_level`（城市线级）、`income_level`（收入层级）、`leads_rank`（线索评级）、`is_repeat_order`（复购）、`user_group`（用户群体），以及**干预前的历史转化基线**（最能反映质量的单一指标）
- **不通过怎么办**：同 CK-02；若质量差异集中在少数高价值线索，额外报一版剔除该部分的稳健性结果

### CK-04 组规模与带班量
- **触发**：两组老师人数或人均带班量差异明显
- **怎么判**：比对两组老师数、人均订单数、人均班级数
- **不通过怎么办**：规模效应会混入 SOP 效应（大组通常有更成熟的协作），需在模型中控制组规模

### CK-05 老师新人占比
- **触发**：默认必查
- **怎么判**：`is_new_renewal_staff` 两组占比对比
- **不通过怎么办**：新人处于学习曲线上，产出天然偏低且波动大；控制该变量，或剔除新人后做稳健性检验

### CK-06 基地 / 团队分布
- **触发**：默认必查
- **怎么判**：`renewal_counselor_group_city`（老师组基地）、`goal_operation_group`（定标团队）、`business_team_tag_id`（承接团队）分布对比
- **不通过怎么办**：基地/团队差异同时带来管理风格与市场差异；控制或分层。注意这与溢出控制存在冲突——同基地便于可比但更易溢出，取舍要写明

### CK-07 期次成熟度对齐
- **触发**：结果指标含续报、退费、完课等滞后指标
- **怎么判**：两组订单的 `term_id` 分布与观察窗是否等长；`term_renewal_end_date` 是否都已过
- **不通过怎么办**：未成熟期次不能与已成熟期次直接比。截断到共同成熟窗口，或按成熟度分层

### CK-08 干预前历史基线
- **触发**：默认必查，**这是最强的可比性证据**
- **怎么判**：取干预前 2–3 期的核心指标，比对两组水平与趋势。水平可以不同（DID 允许），**趋势必须平行**
- **不通过怎么办**：趋势不平行 → DID 失效，改合成控制或事件研究并明确说明识别失败

### CK-09 组内老师异质性
- **触发**：实验组老师组数少，或组内产出高度集中
- **为什么**：组内一两个明星老师可能主导整组结果，「SOP 有效」实为「某个老师强」
- **怎么判**：看组内老师层面产出的分布与集中度（如 top1 老师贡献占比）
- **不通过怎么办**：报老师层面的效应分布而非仅均值；剔除极端老师做稳健性检验

### CK-10 名单口径与生效时间窗
- **触发**：默认必查
- **怎么判**：名单能否唯一匹配到 `counselor_id` / `renewal_staff_employee_no` / `renewal_counselor_group_id`；生效期次是否明确；实验期内是否有老师转组/离职
- **不通过怎么办**：匹配不上就回问用户，不做模糊匹配；人员流动按意向处理（ITT，名单初始归属）为主口径

### CK-11 条件指标的中介覆盖率差异（"X后Y率"对比前必查）
- **触发**：对比任何**条件指标**（分母 = 某中介行为人数，如"到小灶课后的续报率""家长会后的到课率"），默认必查
- **为什么**：中介行为（触达/覆盖）由执行人可控。覆盖率低的组等于对用户做了一次意向筛选，其条件指标被机械抬高——表面领先可能全部来自"筛得狠"，而非策略有效
- **怎么判**：先比两组中介覆盖率（覆盖人数/进班人数）；差距明显（如 >5pp）→ 在稳定聚合粒度上量化「覆盖率↔条件指标」的关系斜率（O/E 标准化 + 加权回归）
- **不通过怎么办**：不得直接对比条件指标。按斜率做覆盖率纠偏（可解释差值 = 覆盖率差÷10pp×斜率，净差 = 实测差−可解释差值），或走《中介覆盖率纠偏与基期DID两层消偏》完整流程

### CK-12 条件指标与覆盖率的机械相关（分子=分母耦合）
- **触发**：量化「覆盖率↔条件指标」关系时，默认必查
- **为什么**：覆盖率的分子正是条件指标的分母，同一批人的抽样噪声会凭空制造负相关——不排除它，纠偏斜率会被高估
- **怎么判**：**随机对半去偏**——组内随机对半，一半人算覆盖率、另一半人算条件指标（噪声耦合被物理切断），≥200 次固定种子看相关方向的稳定性（如 200/200 次同向）
- **不通过怎么办**：去偏后相关消失或反向 → 原始相关主要是机械噪声，不得用于纠偏；去偏后方向保持 → 关系为真，斜率取标准化档进入纠偏

### CK-13 批次/期次结构差异（分层对齐，不进 PS 模型）
- **触发**：两组样本的批次（期次）分布差异明显（如实验组集中在新批次）
- **为什么**：批次是时间维度不是个体属性——把它塞进 PS 模型在概念上错误；完全不处理则两期基线差直接混入效应
- **怎么判**：比两组批次占比；SMD > 0.1 即失衡
- **不通过怎么办**：**批次作分层变量**——每个批次内部各自拟合 PS、各自取共同支撑，再把各批次对照组权重之和缩放为该批次实验组样本量（批次结构对齐到实验组）。事后核验批次 SMD 归零
（沉淀自 2026-08 小灶课课件测试：处理组 73.6% 集中在 07 期，期次 SMD ±0.617，分层对齐后归零；三种处理方式结论一致但"完全不处理"平衡性不达标）

### CK-14 组间固有差距三证据（纠偏后剩余净差能否归因于策略）
- **触发**：非随机分组，且第一层纠偏后仍有剩余净差，默认必查
- **为什么**：即使质量与覆盖率都拉平，两组执行人仍可能存在与策略无关的稳定差距（SOP/能力/成长趋势）——把剩余净差全部记给策略是最常见的高估
- **怎么判**（三证据，任一不过即固有差距成立）：① **历史基期**：无干预差异的历史批次做同口径消偏后净差是否为零；② **A/A 校验**：干预触达不到的人群（未发生中介行为者）两组是否仍有显著差异；③ **覆盖率匹配**：覆盖率拉平的对照单元直接比是否仍有差距
- **不通过怎么办**：以基期同口径净差为基线做 **DID 差分**（最终净值 = 现期净差 − 基期净差），显著性用整群 bootstrap；并检查平行趋势——基期优势逐期走强时 DID 偏乐观，需在报告局限中写明方向

## 实验分析报告结构规范（mth_experiment_report_spec）

实验类分析的**交付物结构规范**。适用于 AB 实验报告、准实验评估报告、因果分析报告三类产物。核心原则：结论先行、证据可追、把「统计显著」与「值得做」分开说。

## 1 固定骨架（七段，顺序不可调）
```
① 结论与建议     —— 上线 / 不上线 / 继续观察，一句话给完，附核心指标效应量与 CI
② 实验概况       —— 场景、假设、处理定义、分流单位与比例、人群、时间窗、数据源
③ 有效性校验     —— SRM、基线均衡、样本量达成率、指标成熟度；不通过则报告到此为止
④ 核心指标结果   —— 效应量 + 95% CI + 相对提升 + p 值 + 是否越过 MDE
⑤ 护栏指标结果   —— 逐条给出，任一显著恶化必须在①中明示
⑥ 机制与异质性   —— 次要指标解释「为什么」；子群结论标注证据等级
⑦ 局限与后续     —— 识别假设、未排除的偏差、需要补的验证
```

## 2 结论先行的写法
第一段必须能独立回答业务方的三个问题：**有没有效？效应多大？要不要上？**

```
建议上线。核心指标续报率实验组 32.4% vs 对照组 30.1%，绝对提升 2.3pp
（95% CI [0.9pp, 3.7pp]），相对提升 7.6%，超过上线门槛 1.5pp；
护栏指标退费率与客单价均无显著恶化。
```

反例（禁止）：「实验组表现较好，建议继续观察」——没有效应量、没有 CI、没有判定标准。

## 3 数字呈现规范
- 率：百分号保留 1 位（`32.4%`）；率的差值用 `pp`（百分点）并保留 1–2 位，**不要**把 pp 写成 %
- 相对提升单独一列，与绝对提升并列，不可只给相对提升（基线低时相对提升极具误导性）
- 金额 / GMV：保留 2 位小数，标明币种与口径（含税 / 退费后）
- **CI 与效应量必须同框出现**；只给点估计的表格视为未完成
- p 值报到 3 位小数，`p < 0.001` 不再展开；**不设"接近显著"这一档**

标准结果表列序：`指标 | 层级 | 对照 | 实验 | 绝对提升 | 相对提升 | 95% CI | p | 是否越过 MDE | 判定`

## 4 判定语与决策映射（不允许自创档位）
| CI 相对 0 与 MDE 的位置 | 判定 | 建议 |
|---|---|---|
| CI 下界 > MDE | 有效且有业务价值 | 上线 |
| CI 下界 > 0，上界 < MDE | 显著但不值得 | 不上线（成本换不回） |
| CI 完全落在 [-MDE, MDE] | 等价 | 判定无差异，按其他因素决策 |
| CI 跨 0 且跨 ±MDE | 无法判定 | 说明还需多少样本 / 多长时间 |
| 上界 < 0 | 有害 | 停止 / 回滚 |

## 5 证据等级标注（每个结论都要带）
沿用《因果识别清单与偏差排查》的分级：随机实验 > 准实验（假设已证伪） > 控制可观测混杂 > 纯相关。
- 准实验报告的①中必须出现「在【假设】成立的前提下」
- 纯相关的段落禁止使用「带来 / 拉动 / 驱动 / 贡献了」等因果动词
- 探索性子群结论统一后缀「探索性发现，需独立验证」

## 6 可复现信息（放报告末尾，不占正文）
数据源与口径、筛选条件、样本量、指标定义（分子分母）、检验方法与参数、是否使用 CUPED / 多重比较校正、分析日期与数据截止日。用户提供的是本地文件时，记录文件名与行数即可，**不需要**登记为平台资产。

## 7 篇幅纪律
- 结论段 ≤ 5 行；核心指标表 ≤ 1 屏
- 每张图必须回答一个明确问题，回答不了就删
- 不写"由于时间关系未深入"这类免责套话；有局限就写在⑦并给出补救路径


## 中介覆盖率纠偏与基期DID两层消偏（mth_mediator_coverage_debias_did）

当分组**非随机**、且实验组存在一个**可控中介行为**（如某环节的触达/覆盖动作），而要评估的又是**条件指标**（"到过 X 的人群里的 Y 率"，分母 = 中介行为人数）时，直接对比条件指标会同时混入三种偏差。本卡给出「两层消偏」组合打法：中介覆盖率斜率纠偏（第一层）+ 历史基期 DID（第二层），并配整群 bootstrap 检验。

**典型场景**：小灶课课件测试——覆盖率（到小灶课/进班）由老师可控，评估指标是"小灶课后续报率"；实验组覆盖率低 → 高意向筛选 → 条件指标被机械抬高。

## 0 三猜想框架（先立后验，报告故事线即按此展开）
对任何"实验组条件指标领先"的表面结果，先提出三个竞争性解释再逐一验证：
1. **猜想①线索/样本质量偏差**：分流不均 → PSM 检验（通常影响小，但必须排除）
2. **猜想②中介覆盖率的选择效应**：低覆盖 = 意向筛选，会系统性改变**所有**条件指标 → 量化斜率并纠偏
3. **猜想③组间固有差距**：即使质量与覆盖率都一致，两组执行人本身仍可能有稳定差距（SOP/能力）→ 历史基期检验

## 1 第一步：PSM 对齐样本质量（批次作分层变量）
- PS 协变量**只放个体属性**（渠道、城市线级、年级等线索质量项）；**批次/期次是时间维度不是个体属性，不进 PS 模型**——在每个批次内部各自拟合 PS、各自取共同支撑（区间交集 + 处理组双侧 1% 修剪），ATT 加权（处理组=1，对照组=e/(1−e)），再把各批次对照组权重之和缩放为该批次处理组样本量（批次结构对齐到处理组）
- 平衡标准：各协变量水平 |SMD| < 0.1；加权比例的标准误用 Kish ESS = (Σw)²/Σw²

## 2 第二步：量化「中介覆盖率 ↔ 条件指标」纠偏斜率
- **聚合粒度**：用分流单位的上一级稳定聚合（如老师组×批次），避免小分母噪声淹没信号
- **O/E 标准化**：对覆盖率与条件指标分别拟合逻辑回归（协变量 = 线索质量项 × 批次），调整值 = 实际 − 期望 + 全样本均值，消掉线索质量混杂后再算加权 Pearson r 与 WLS 斜率
- **机械相关排除（必做）**：覆盖率的分子 = 条件指标的分母，同批人的抽样噪声会凭空制造负相关。用**随机对半去偏**验证：组内随机对半，一半算覆盖率、另一半算条件指标，≥200 次固定种子看方向是否保持
- **单档原则**：纠偏斜率在报告正文只采用一个主档（标准化口径）；去偏档/分期档做敏感性入附录
- 注意方向可能相反：同为条件指标，"X后转化率"常与覆盖率负相关（稀释），"X后到播率"可能正相关（运营勤奋度联动）——每个指标单独量化，不共用斜率

## 3 第一层消偏：覆盖率纠偏
```
可解释差值 = (实验组覆盖率 − 对照组覆盖率) ÷ 10pp × 该指标纠偏斜率
第一层净差 = 实测差 − 可解释差值      （p 沿用实测差标准误，斜率视为常数）
```

## 4 验证猜想③：组间固有差距的三证据
1. **历史基期检验（主证据）**：取无干预差异的历史批次，对同一批执行人做同一套 PSM + 同口径覆盖率消偏——若基期净差仍稳定不为零，固有差距成立
2. **A/A 校验**：干预触达不到的人群（未发生中介行为者）两组仍有显著差异 → 干预之外的组间差异确凿存在
3. **覆盖率匹配对比**：只取覆盖率落在实验组区间内的对照单元直接比——拉平后差距仍在（注意该差距是"干预+固有差距"混合，只用于证明存在，量级以基期口径为准）

## 5 第二层消偏：DID 差分固有差距
```
最终净值（干预增量）= 现期净差（覆盖率消偏后） − 基期净差（覆盖率消偏后）
```
- 等价于「覆盖率消偏 + 双重差分」。两个识别前提：①斜率跨期稳定（多档敏感性覆盖）；②固有差距跨期平行——若基期分期数据显示处理组优势逐期走强，DID 会**高估**干预增量，"净值≈0"的结论在保守方向上反而更稳
- **显著性检验用整群 bootstrap**：按各期独立单元整群重抽（现期 = 分流单位；基期按执行人归属单元），PSM 权重与 O/E 期望全量估计一次后固定，≥4,000 次固定种子；实验假设为方向性时用**单侧 p = P(DID* ≤ 0)**（H1: 干预为正）。整群重抽天然吸收聚类效应，禁止用学员级方差直接检验
- 斜率同步重抽（在聚合单元上重估 WLS 斜率）作为敏感性

## 6 检验力披露与样本量敏感性（必附）
- DID 合并两期方差，检验力显著低于单期对比：报告必须给出 bootstrap SE、95% 百分位 CI，并明示"当前样本无法排除 ±X pp 以内的真实效应"
- 附「样本量倍数 × 达到显著所需效应」表（SE ∝ 1/√k，门槛 = z×SE，注明单/双侧与是否含功效）
- **给出更优路径**：与其等比扩样，不如下一轮实验直接把中介覆盖率拉平——无需斜率纠偏与 DID，显著门槛大幅下降

## 7 报告呈现
- 两层消偏用**瀑布图**一张讲完：实测差 → 扣覆盖率可解释 → 第一层净差 → 扣固有差距 → 最终净值
- bootstrap 抽样分布直方图标注观测值、零线、95% CI 与单侧 p
- 核心结论 ≤4 条：净效应判定 → 显著的负向/风险信号 → 对北极星指标的折算 → 下一步建议
